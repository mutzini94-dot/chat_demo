01 · 설계 원칙 Principles

무엇을 먼저, 왜 그 순서로

두 플랫폼 분석의 결론은 명확하다 — 실시간성·안전장치·수익결합 이 셋이 채팅의 뼈대다. 로드맵은 "체감 가치가 크고 의존성이 낮은 것"부터 쌓는다.

P1

안전은 1일차부터

클린봇 L1(사전)+슬로우모드+수동 삭제는 MVP 필수. 안전 없는 오픈 채팅은 하루면 무너진다.

P2

후원=관계 맥락

후원 채팅은 단순 기능이 아니라 등급·권한과 엮인다. 초기에 후원-등급 연결 고리를 심어둔다.

P3

확장 대비 설계

등급→권한 매핑, 서버 태깅+클라 렌더 분리, 방 분산 여지를 초기 스키마에 반영한다.

02 · 단계별 로드맵 Phased Roadmap

Phase 0 → 4

범례 — 기본 채팅 코어 · 수익 후원/구독 · 운영 모더레이션 · 봇 클린봇/자동화

PHASE 0
기반 인프라
~3주

실시간 채팅 채널

화면에 메시지가 흐르는 최소 골격. 이후 모든 기능이 여기 얹힌다.

  • 기본WebSocket 채널 상시 연결·재연결·백오프
  • 기본메시지 렌더 뱃지·닉·본문, 자동 스크롤/잠금
  • 기본로그인 게이트 열람=비로그인, 전송=로그인
  • 기본표시 버퍼 상한 가상 스크롤 기초
WebSocket세션/토큰메시지 스키마
PHASE 1
MVP · 첫 운영
~4주

보낼 수 있고, 지킬 수 있는 채팅

진짜 방송에 투입 가능한 최소 안전 세트. "전송 + 최소 모더레이션 + 최소 후원".

  • 기본텍스트 전송 글자수 제한·차단 사유 피드백
  • 기본기본 이모티콘 피커·인라인 렌더
  • 운영금칙어 + 클린봇 L1 정규화·자모 사전
  • 운영슬로우 모드 전송 간격 설정
  • 운영매니저 삭제·타임아웃 아이디 지정
  • 운영고정 공지 상단 고정/해제
  • 수익채팅 후원(텍스트) 금액 강조 카드
  • 기본시스템 메시지 입장·후원 알림
클린봇 L1슬로우모드매니저후원 채팅
PHASE 2
성장 · 팬덤
~6주

팬을 구분하고, 스팸을 거른다

구독·팔로우·개인화로 팬덤을 형성하고, 클린봇을 행동 기반까지 확장.

  • 수익구독 개월 뱃지·전용 이모티콘
  • 운영팔로워/구독 전용 전송 조건(경과시간)
  • 봇클린봇 L2 도배·유사반복·광고 탐지
  • 봇개인 클린봇 토글 서버 태깅+클라 가림
  • 운영신고 사용자/메시지 신고 큐
  • 기본프로필 카드 닉 클릭→관리 액션
  • 기본채팅 팝업·설정 글자크기·투명도
  • 수익영상/미션 후원 오버레이 연동
클린봇 L2개인 필터구독 뱃지신고
PHASE 3
확장 · 차별화
~8주

등급 경제와 지능형 운영

숲 수준의 등급-권한 결합, ML/LLM 클린봇, 다시보기·참여형으로 차별화.

  • 수익팬 등급 체계 후원 개수→등급 자동
  • 운영등급별 채팅 권한 얼리기·등급 참여조건
  • 봇클린봇 L3 ML/LLM 애매구간 문맥판단
  • 기본다시보기 채팅 VOD 타임라인 동기
  • 기본채팅 번역 자동/수동
  • 기본참여형 투표·승부예측
  • 기본귓속말 1:1 + 수신 허용
  • 운영운영 대시보드 오탐률·차단 로그
클린봇 L3등급 경제다시보기번역투표/예측
PHASE 4
규모 · 자동화
지속

대형 방송을 감당하는 운영

동시접속 폭증과 운영 인력 한계를 방 분산·자동화로 해결.

  • 기본중계방 분산 본방 만원→분산·정책 동기화
  • 봇전자비서(룰봇) 자동 명령·응답
  • 봇AI 요약/민심 방송 요약·키워드
  • 운영클린봇 피드백 루프 리뷰→사전/모델 갱신
  • 기본채널 샤딩 팬아웃 확장
  • 수익커머스 연동 상품·수익 공유
중계방전자비서AI 요약샤딩
03 · 클린봇 단계별 이식 Cleanbot Tiers × Phases

클린봇은 한 번에 만들지 않는다

클린봇은 3계층을 단계에 나눠 붙인다. L1은 MVP 필수, L2는 성장기, L3(ML/LLM)는 트래픽·예산이 붙는 확장기에.

L1 · PHASE 1

사전 · 규칙

동기 · μs~1ms

한국어 정규화(NFKC·leet·반복축약)+자모 분해 후 Aho-Corasick 사전 매칭. 예외어(allowlist) 우선. 확정 욕설=인라인 차단.

L2 · PHASE 2

통계 · 스팸

동기 · 인메모리/Redis

사용자 슬라이딩 윈도우로 도배·유사반복·초당다발·광고/연락처·저엔트로피 탐지. 점수 합산→강도별 임계값으로 블라인드.

L3 · PHASE 3

ML · LLM 문맥

비동기 · 애매구간 한정

40~80점 애매 구간만 한국어 욕설 분류기 또는 LLM 배치 판정. 전량 아님(비용). 사후 블라인드에만 적용.

🛡️

공통 원칙 — 서버는 판정, 클라는 렌더

차단(block)만 서버가 미전송하고, 의심(blind)은 태그만 붙여 브로드캐스트한다. 최종 가림 여부는 시청자의 "개인 클린봇" 설정이 결정한다. 이 분리가 개인 필터·오탐 대응·투명성의 전제다.
